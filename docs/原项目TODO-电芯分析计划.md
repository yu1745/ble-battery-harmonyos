## 电芯分析计划

目标：基于每次刷新得到的 15 串电芯电压、总电流、SoC 和时间序列，做一个轻量、可解释的电芯特性分析，输出“可能偏弱 / 可能偏高 / 可能内阻偏大 / 表现稳定”这类推测性标记。

### 1. 数据采集

- 每次刷新保存一条快照
- 快照字段至少包含：
  - `timestamp`
  - `current`
  - `soc`
  - `cellVoltages`
  - `avgCellVoltage`
  - `minCellIndex`
  - `maxCellIndex`
  - `spreadMv`
- 仅保留最近 `N` 条有效样本，初版建议 `200 ~ 500`

### 2. 有效样本过滤

- 小电流样本不纳入主要判断，初版阈值可设为 `abs(current) >= 2A`
- 压差过小的样本不纳入极值判断，初版阈值可设为 `spreadMv >= 8`
- 样本不足时不给强结论，只显示“样本不足”

### 3. 每节电芯的基础统计

为 15 节电芯分别维护：

- 成为最低压的次数
- 成为最高压的次数
- 放电时成为最低压的次数
- 充电时成为最高压的次数
- 相对平均值的累计偏差
- 相对平均值的平均偏差
- 相对平均值的波动幅度

### 4. 第一版判断规则

#### 可能偏弱

满足以下倾向时标记：

- 放电时多次成为最低压
- 长期相对平均值偏低
- 在中大电流下更明显

#### 可能偏高

满足以下倾向时标记：

- 充电时多次成为最高压
- 长期相对平均值偏高

#### 可能内阻偏大

满足以下倾向时标记：

- 电流升高时明显更容易掉到最低
- 电流回落后又较快回到中间区间

#### 表现稳定

满足以下倾向时标记：

- 很少成为最高或最低
- 长期偏离平均值较小
- 波动幅度较小

### 5. 结果展示

- 在每节电芯卡片上加简短标记，例如：`弱`、`高`、`阻`、`稳`
- 在电芯区域下方增加分析摘要
- 每条判断显示置信度：`低 / 中 / 高`

### 6. 置信度策略

- 有效样本 `< 20`：低
- 有效样本 `20 ~ 100`：中
- 有效样本 `> 100`：高

### 7. 本地持久化

- 使用 `localStorage` 保存最近一段历史快照和分析结果
- 为历史数据设置上限，避免无限增长
- 后续如果数据量变大，再考虑迁移到 `IndexedDB`

### 8. 实施顺序

1. 持久化每次轮询的快照
2. 完成“放电最低次数 / 充电最高次数”统计
3. 加入“长期偏离平均值”统计
4. 输出第一版推测标签
5. 再评估是否需要更复杂的分析模型
