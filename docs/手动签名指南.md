# 手动签名指南 —— 不装 DevEco Studio 的完整流程

> 结论:**DevEco Studio 不是必须的**。签名文件从 **AGC(AppGallery Connect)网页控制台**申请,CSR/密钥本地生成,签名用 OpenHarmony 官方 `hap-sign-tool` 命令行完成。DevEco 的"自动签名"只是把这几步串了起来而已。

## 文件角色速查

| 文件 | 谁生成 | 说明 |
|---|---|---|
| `.p12` 密钥库 | **本地**(本仓库已生成) | 私钥,签名时用;已生成 `sign-tool/blebattery-debug.p12`,密码 `blebattery2025`(可用 `SIGN_KEY_PWD` 环境变量覆盖,重新生成) |
| `.csr` 证书请求 | **本地**(本仓库已生成) | 公钥申请书;已生成 `sign-tool/blebattery-debug.csr` |
| `.cer` 调试证书 | **AGC 网页**下载 | 上传 CSR 后签发,绑定你的开发者账号 |
| `.p7b` 调试 Profile | **AGC 网页**下载 | 绑定包名 + 证书 + 设备 UDID 列表 |

## 前提条件

- 一个**实名认证**的华为开发者账号(个人账号即可,免费注册;实名在"账号中心"完成,个人需身份证/人脸)。
- 一台 HarmonyOS NEXT 真机 + 数据线(开启开发者模式与 USB 调试)。

## 步骤一:取手机 UDID

```bash
~/harmonyos/command-line-tools/sdk/default/openharmony/toolchains/hdc shell bm get --udid
# 备选: hdc shell param get const.product.udid
```

## 步骤二:AGC 网页操作(浏览器完成,共 4 次)

入口:<https://developer.huawei.com/consumer/cn/service/josp/agc/index.html> 登录后进入 **"证书、APP ID与Profile"**(有的版本叫"用户与访问"下的同名菜单)。

1. **APP ID → 新增**:包名填 `com.yu1745.blebattery`(与工程 AppScope/app.json5 一致)。
2. **证书 → 新增证书**:类型选"调试证书",上传本仓库的 `sign-tool/blebattery-debug.csr`,提交后**下载 `.cer`**,重命名为 `blebattery-debug.cer`。
   - 注意:调试证书每个账号数量有限(通常 1 张,有效期以页面显示为准)。如果你以前用 DevEco 自动签名申请过调试证书,要么吊销重办(用本 CSR),要么改用那次对应的 `.p12` 密钥库。
3. **设备 → 注册设备**(调试 Profile 用):粘贴步骤一的 UDID。
4. **Profile → 新增**:类型"调试",选包名 `com.yu1745.blebattery` + 刚才的证书 + 勾选设备,提交后**下载 `.p7b`**,重命名为 `blebattery-debug.p7b`。

把两个文件放进本仓库 `signing/` 目录(该目录已 gitignore,不会误传密钥):

```
signing/blebattery-debug.cer
signing/blebattery-debug.p7b
```

## 步骤三:本地签名 + 安装

```bash
./build.sh          # 构建 entry-default-unsigned.hap
./sign.sh           # 签名 → dist/blebattery-signed.hap (内部会 verify-app 自检)
./sign.sh install   # 或直接签名+安装到连接的真机 (调用命令行工具里的 hdc)
```

`hap-sign-tool.jar` 脚本会自动从 OpenHarmony 官方仓库下载
(<https://github.com/openharmony/developtools_hapsigner> → `dist/hap-sign-tool.jar`,本仓库 sign-tool/ 目录已放一份)。

## 常见问题

| 报错 | 原因/处理 |
|---|---|
| `9590086 cert is invalid` / 安装时校验失败 | .cer 与 .p12 不配对 —— 确认 AGC 上传的是本仓库的 CSR |
| `9590090 profile illegal` | .p7b 包名/设备不匹配 —— Profile 里包名必须是 `com.yu1745.blebattery`,且本机 UDID 已注册 |
| `hdc install failed [install bundle due to invalid signature]` | 调试 Profile 过期或证书吊销 —— 回 AGC 重新生成 .p7b |
| 想换密码 | `rm sign-tool/*.p12 *.csr && SIGN_KEY_PWD=新密码 ./sign.sh`(重新生成后需重新上传新 CSR 申请证书) |

## 安全说明

- `blebattery-debug.p12` 只是**调试**私钥,离开 AGC 签发的对应 `.cer/.p7b` 没有任何用处;本仓库为私有仓库,故直接提交了该文件方便多机签名。介意的话删除它并用 `SIGN_KEY_PWD=xxx ./sign.sh` 重新生成。
- **发布/上架**必须另外申请"发布证书 + 发布 Profile"(AGC 同一页面,无需设备注册),发布包用 `sign-app` 同一命令换文件即可。
